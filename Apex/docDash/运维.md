# docDash 运维手册

> [!info] 端口速查
> | 环境 | 前端 | 后端 API |
> | --- | --- | --- |
> | 本地 npm | `5173` | `3000` |
> | 本地 Docker Compose | `3010` | `3009` |

## 一、本地开发

### 方式一：npm 直接运行

**Step 1 — 安装依赖**

```bash
# 后端（项目根目录）
npm install

# 前端
cd frontend && npm install
```

**Step 2 — 启动后端（端口 3000）**

```bash
npm run dev
```

**Step 3 — 启动前端（端口 5173）**

```bash
npm run dev:frontend
```

访问：http://localhost:5173

### 方式二：Docker Compose

```bash
docker-compose up --build
```

- 前端：http://localhost:3010
- 后端 API：http://localhost:3009

## 二、生产部署

### 环境信息

| 项目      | 值                                   |     |
| ------- | ----------------------------------- | --- |
| 本地发布机目录 | `F:\projects\ai-alert-rule-display` |     |
| 服务器     | `ubuntu@34.220.248.234`             |     |
| 登录密钥    | `dev.pem`（位于发布机目录下）                 |     |
| 服务器项目路径 | `/data/projects/doc-dash`           |     |
| 部署方式    | 由 Claude 调用本机 Docker 部署             |     |

### 操作步骤

**Step 1 — 登录服务器**

在本地发布机目录执行：

```bash
cd F:\projects\ai-alert-rule-display
ssh -i .\dev.pem ubuntu@34.220.248.234
```

**Step 2 — 拉取最新代码**

```bash
cd /data/projects/doc-dash
git pull
```

**Step 3 — 启动 AI 部署助手**

```bash
cd /data/obsidian-mywork/
claude --dangerously-skip-permissions
```

**Step 4 — 下发部署指令**

直接让 AI 部署程序到本机 Docker，按需选择范围：

- 全量发布（前后端）：
  `请帮我发布doc-dash项目到生产，前后端都要发`
- 仅发布前端：
  `请帮我发布doc-dash项目到生产，只发前端`

> [!warning] 项目名拼写
> 原始记录中指令写的是 `doc-dsah`，实际项目名为 `doc-dash`，下发指令时请使用正确拼写。
