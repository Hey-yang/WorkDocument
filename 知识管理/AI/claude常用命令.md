# Claude Code 常用命令

## 一、三种工作模式

通过 `Shift+Tab` 循环切换，对应**安全确认、自动执行、只读规划**三种场景。

| 模式 | 界面提示 | 行为 | 适用场景 |
| --- | --- | --- | --- |
| Default 默认 | `? for shortcuts` | 修改文件、执行命令前都需确认 | 日常开发、不确定 AI 行为、敏感项目 |
| Auto-Accept 自动接受 | `accept edits on` | 文件修改自动执行，shell 命令仍需确认 | 重复性修改、批量替换、简单功能 |
| Plan Mode 计划 | `plan mode on` | 纯只读，只分析规划，不动代码 | 阅读陌生项目、架构分析、方案设计 |

> [!tip] 推荐工作流
> Plan Mode 理清架构 → 确认方案 → 切 Auto-Accept 快速执行 → 完成后切回 Default 保证安全。

## 二、交互界面与快捷键

界面底部显示模式、模型、用量信息，中间是对话输入框，支持自然语言、文件引用、图片粘贴。

| 快捷键 | 作用 |
| --- | --- |
| `Shift+Tab` | 循环切换三种模式 |
| `Ctrl+C` | 中断当前生成 |
| `Ctrl+B` | 将任务挂到后台运行 |
| `ESC` 两次 | 清空输入框 |
| `Ctrl+T` | 显示 / 隐藏任务面板 |
| `Ctrl+O` | 显示详细输出 |
| `Ctrl+Shift+Z` | 撤销上一步操作 |
| `Alt+V` | 粘贴图片（Windows） |
| `\ + Enter` | 输入框内换行，不发送消息 |

## 三、斜杠命令

### 会话控制

| 命令 | 作用 | 备注 |
| --- | --- | --- |
| `/clear` | 清空对话历史 | 相当于重启会话但不退出；切换任务、上下文混乱、回答跑偏时用 |
| `/resume` | 恢复之前的会话 | 按 ID 或名称恢复，不带参数则打开会话选择器；别名 `/continue` |
| `/compact` | 压缩上下文 | Token 接近上限时总结历史、保留关键信息 |
| `/rewind` | 回退上一步操作 | 撤销 AI 上一步的修改 |
| `/rename` | 重命名会话 | 原记录未附说明 |

`/compact` 可附加说明指定保留内容：

```
/compact 保留登录模块相关内容
```

`/resume` 与 `/clear` 配合使用：`/clear` 清空时会丢掉上下文，想之后再回来，可以先给上一段对话起个名字（`/clear 登录模块重构`），之后在 `/resume` 的选择器里按名字找回。后台会话在列表里会标记为 `bg`。

### 项目与记忆

| 命令 | 作用 |
| --- | --- |
| `/init` | 扫描代码结构，生成 `CLAUDE.md` 项目知识库 |
| `/memory` | 打开并编辑 `CLAUDE.md`，手动添加规范、规则、禁忌 |
| `/add-dir 目录路径` | 让 AI 同时读取多个目录 |

`/init` 生成的内容包括：项目概述、技术栈、目录结构、常用命令、开发规范、注意事项。每次启动都会先读取该文件，实现**持久项目记忆**。

`/memory` 涉及三级记忆：

- **项目记忆**：当前项目生效
- **用户记忆**：所有项目全局生效
- **自动记忆**：AI 自动记录重要规则

### 配置与模型

| 命令 | 作用 |
| --- | --- |
| `/config` | 配置面板：主题、自动压缩、快速模式、输出格式等 |
| `/model` | 切换 AI 模型，平衡速度与能力 |

常用模型：

| 模型 | 特点 | 适合 |
| --- | --- | --- |
| Haiku | 最快、最便宜 | 简单问题 |
| Sonnet | 均衡 | 日常编码首选 |
| Opus | 最强 | 复杂架构、重构 |

### 状态与诊断

| 命令 | 作用 |
| --- | --- |
| `/status` | 查看版本、工作目录、模型、配置、用量 |
| `/cost` | 统计当前会话输入输出 Token 与预估费用 |
| `/tasks` | 查看后台运行中的任务（编译、测试等） |
| `/doctor` | 环境诊断：依赖、权限、API 连通性 |

### 帮助

| 命令 | 作用 |
| --- | --- |
| `/help` | 列出所有可用指令与说明 |

## 四、启动参数（CLI）

	在终端启动 `claude` 时附加，不是斜杠命令。 

| 参数 | 作用 | 适用场景 |
| --- | --- | --- |
| `--dangerously-skip-permissions` | 跳过所有权限确认（文件编辑、Bash 命令、MCP 工具），全程自动批准 | 隔离环境、受控目录、自动化 / 无人值守部署 |

```bash
claude --dangerously-skip-permissions
```

> [!warning] 风险
> 该参数会让 AI 在**无任何提示**的情况下执行任意命令，包括删除文件、`git push`、调用外部接口。只在专用机器、容器或可随时回滚的目录里使用；日常开发建议仍用 Default 模式逐次确认。
